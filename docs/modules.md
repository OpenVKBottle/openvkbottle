# Dependencies customisation

openvkbottle автоматически выбирает лучшую альтернативу для стандартных библиотек.

Эти библиотеки не указаны в зависимостях, поэтому вы должны установить их сами.

## JSON

В порядке убывания: `orjson`, `hyperjson`, `ujson`, `json`

## Logging

В порядке убывания: `loguru`, `logging`

!!! warning "Внимание"
    Мы настоятельно рекомендуем использовать `loguru` вместо `logging`. Возможно, он станет обязательной зависимостью в будущих релизах.

!!! info "Примечание"

    По умолчанию уровень логирования выставлен на `DEBUG`.
    Изменить это вы можете так:

    === "logging"

        ```python
        import logging

        logging.getLogger("openvkbottle").setLevel(logging.INFO)
        ```

    === "loguru"

        === "Установить определенный уровень"

            ```python
            import sys
            from loguru import logger

            logger.remove()
            logger.add(sys.stderr, level="INFO")
            ```

            Или установить [переменную окружения](https://en.wikipedia.org/wiki/Environment_variable) `LOGURU_LEVEL`

        === "Отключить логирование полностью"

            ```python
            from loguru import logger

            logger.disable("openvkbottle")
            ```

## Готовый пресет логирования и его отключение

По умолчанию openvkbottle сам настраивает логирование "из коробки": добавляет обработчик
вывода в `stderr`, красивое цветное форматирование сообщений и перенаправляет
`warnings` в логгер. Это сделано намеренно — на старте работы с библиотекой (особенно
для новичков) гораздо приятнее сразу видеть аккуратные цветные логи, чем разбираться
с настройкой `logging`/`loguru` с нуля.

Однако это же поведение мешает, когда openvkbottle используется как часть более крупной
системы, где логирование уже настроено самостоятельно — например, есть отправка логов
во внешнюю систему (remote log push), структурированные логи (JSON), собственные
хендлеры и форматтеры и т.п. В этом случае пресет openvkbottle конфликтует с
инфраструктурной настройкой логирования и его нужно отключать.

Чтобы отключить встроенный пресет логирования, установите переменную окружения
`openvkbottle_SKIP_LOGGING_PRESET` (в любое непустое значение, например `1`) **до**
импорта `openvkbottle`:

```bash
export openvkbottle_SKIP_LOGGING_PRESET=1
```

```python
import os

os.environ["openvkbottle_SKIP_LOGGING_PRESET"] = "1"

import openvkbottle  # noqa: E402
```

При включённом флаге openvkbottle не добавляет свой обработчик/форматтер и не
переопределяет `warnings.showwarning`, а просто получает обычный логгер
(`logging.getLogger("openvkbottle")` для `logging`, либо логгер `loguru` без
дополнительной настройки автоинициализации). Логи при этом продолжают писаться
через тот же логгер `openvkbottle` и полностью подчиняются вашей собственной
конфигурации логирования.
